# Vista: trigger cues and export cue lists

Use the Vista action node to export cue lists and trigger basic Vista OSC commands.

> [!WARNING]
> Vista support carries a beta badge in the node catalog and Device list. It is available in all builds. Test it before you rely on it in a live show.

Trigger your Vista lighting and show system from Relay.

## Setup

1. Connect to a supported Vista device.
2. In [Automation View](../dashboards/automation.md), add the **Vista** action node.

## What it can do

Export cue lists and trigger basic Vista OSC commands directly from Relay.
