# Security reports

Do not disclose exploitable vulnerabilities, credentials, customer information, or private diagnostic logs in public issues.

Send sensitive reports privately to support@ondeckapps.com. Include the affected version, a description, reproduction steps using synthetic data, and the potential impact. Do not send working credentials or customer files unless a maintainer requests them through an agreed private channel.

This is a community project with no guaranteed response time or security service-level agreement. The current development branch is the primary maintenance target; no support lifetime is promised for old paid builds or third-party forks.
